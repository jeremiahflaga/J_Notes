# Preface

## Who Is This Book For?

• You want a simple introduction to domain-driven design and want to learn how it is different from object-oriented design or database-first design.

You don’t need to have prior knowledge of domain-driven design or functional
programming in order to read this book. This is an introductory book and all
the important concepts will be explained as we need them.


## Working with the Code in This Book

If you are playing with the example code in conjunction with reading this book, I suggest that you type it into a file and **evaluate it interactively rather than compiling it**. For how to do this, search the Internet for “F# scripting tips.”

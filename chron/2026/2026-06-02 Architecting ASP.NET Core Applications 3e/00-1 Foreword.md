# Foreword

Carl-Hugo Marcotte’s Architecting ASP.NET Core Applications is fully in line with my preferred way to teach others software engineering concepts.

Additionally, testing approaches are built into the content of this book at every opportunity. This is a refreshing take on software engineering material where there’s typically a hyper-focus on design,
performance, and computer science.

For those readers that have more experience developing web applications in C#, I believe that this book will help to reinforce good design decisions and offer you some alternative perspectives on things you are already familiar with.

_Nick Cosentino, Principal Software Engineering Manager at Microsoft_
